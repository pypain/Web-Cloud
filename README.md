# Личное облако

Русский адаптивный файловый менеджер в стиле «Тихий архив»: тёплая тёмная палитра, медные акценты, заголовки Georgia и интерфейс Manrope.

## Запуск

Node.js 22 или новее.

```sh
npm ci
npm run dev
```

`npm run build` создаёт статический сайт в `dist`. `npm run preview` запускает просмотр сборки.

## Возможности

- Загрузка файлов кнопкой и перетаскиванием, статус сохранения и скачивание.
- Папки, хлебные крошки, поиск по всем активным файлам, сортировка, список и плитки.
- Выделение нескольких файлов, контекстное меню, переименование и перемещение.
- Предпросмотр изображений, текста и исходников (включая `.py` с типом octet-stream), PDF и поддерживаемых браузером аудио/видеоформатов.
- Корзина, восстановление и удаление навсегда с подтверждением.
- Общие ссылки с ограниченным сроком и отзывом в серверном режиме; подготовка к обмену в локальном режиме.
- Запуск небольших Python-скриптов в изолированной среде браузера, ввод и вывод, остановка и лимит 10 секунд.
- Синхрокопия на ноут с Arch: докачка, проверка SHA‑256, статус в админке и удаление копий после окончательного удаления исходника; [установка](laptop/README.md).
- Реальный объём сохранённых файлов, включая корзину.
- Вход `/cloud/auth/`, закрытая регистрация и управление аккаунтами в `/cloud/admin/` после миграции на аккаунты.
- Профиль: имя, название архива, аватар, цвет акцента и анимации; в серверном режиме настройки синхронизируются между устройствами.
- Карточки папок, миниатюры изображений в плитках, нижняя мобильная навигация и полноэкранный предпросмотр на телефоне.
- Управление с клавиатуры и поддержка настройки уменьшения анимаций.

По умолчанию разработка запускается с IndexedDB: данные отдельно для браузера и адреса сайта. Очистка данных сайта удаляет локальные файлы. Для серверного режима сборка запускается с `VITE_SERVER_STORAGE=1`; Python backend и закрытый nginx-маршрут описаны в [backend/README.md](backend/README.md).

Серверная версия поддерживает очередь, прогресс по каждому файлу, паузу и возобновление частями после обрыва. После закрытия страницы исходные файлы необходимо выбрать снова. Публичные ссылки на файлы доступны с ограничением срока действия и отзывом; ссылки на папки пока не поддерживаются. Папки не скачиваются архивом; скачивание нескольких файлов может потребовать разрешения браузера. Независимые резервные копии требуют отдельной настройки.

## Проверки

```sh
npm test
```

Тесты Playwright используют `/usr/bin/chromium`. Для другой машины измените путь браузера в `playwright.config.js` или используйте установленный Playwright Chromium. Проверяются сохранение после перезагрузки, скачивание, предпросмотр, переименование, перемещение, корзина, восстановление вложенных файлов и мобильная навигация. Дополнительные проверки охватывают сохранение профиля без изменения файлов, массовую загрузку, миниатюры, обмен, управление фокусом в предпросмотре, уменьшение анимаций и отсутствие горизонтального переполнения при ширине от 320 до 1440 px.

Предпросмотр поддерживает FLAC, включая файлы с неопределённым MIME: воспроизведение и перемотка выполняются в браузере, сервер не перекодирует оригинал. Выделение мышью поддерживает рамку, Shift для диапазона в текущем порядке и Ctrl/⌘ для добавления отдельных элементов. В настройках профиля доступны тёмная, светлая и системная темы; на сервере тема сохраняется отдельно для каждого аккаунта.
