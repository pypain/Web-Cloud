# Личное облако

Русский адаптивный файловый менеджер в стиле «Тихий архив»: тёплая тёмная палитра, медные акценты, заголовки Georgia и интерфейс Manrope.

## Запуск

Node.js 22 или новее.

```sh
npm ci
npm run dev
```

`npm run build` создаёт статический сайт в `dist`. `npm run preview` запускает просмотр сборки.

## Возможности

- Загрузка файлов кнопкой и перетаскиванием, статус сохранения и скачивание.
- Папки, хлебные крошки, поиск по всем активным файлам, сортировка, список и плитки.
- Выделение нескольких файлов, контекстное меню, переименование и перемещение.
- Предпросмотр изображений, текста, PDF и поддерживаемых браузером аудио/видеоформатов.
- Корзина, восстановление и удаление навсегда с подтверждением.
- Подготовка файлов к обмену через раздел «Общие ссылки».
- Реальный объём сохранённых файлов, включая корзину.
- Локальный профиль: имя и название архива сохраняются на этом устройстве.
- Карточки папок, миниатюры изображений в плитках, нижняя мобильная навигация и полноэкранный предпросмотр на телефоне.
- Управление с клавиатуры и поддержка настройки уменьшения анимаций.

Данные сохраняются в IndexedDB, отдельно для браузера и адреса сайта. Это **frontend без серверного хранилища**: публичные ссылки, авторизация и синхронизация с VPS не реализованы. Очистка данных сайта удаляет локальные файлы. Папки не скачиваются архивом; скачивание нескольких файлов может потребовать разрешения браузера.

## Проверки

```sh
npm test
```

Тесты Playwright используют `/usr/bin/chromium`. Для другой машины измените путь браузера в `playwright.config.js` или используйте установленный Playwright Chromium. Проверяются сохранение после перезагрузки, скачивание, предпросмотр, переименование, перемещение, корзина, восстановление вложенных файлов и мобильная навигация. Дополнительные проверки охватывают сохранение профиля без изменения файлов, массовую загрузку, миниатюры, обмен, управление фокусом в предпросмотре, уменьшение анимаций и отсутствие горизонтального переполнения при ширине от 320 до 1440 px.
