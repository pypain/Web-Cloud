# Личное облако

Русский адаптивный файловый менеджер в графитовом стиле с фиолетовыми акцентами.

## Запуск

Node.js 22 или новее.

```sh
npm ci
npm run dev
```

`npm run build` создаёт статический сайт в `dist`. `npm run preview` запускает просмотр сборки.

## Возможности

- Загрузка файлов кнопкой и перетаскиванием, скачивание.
- Папки, хлебные крошки, поиск по всем активным файлам, сортировка, список и плитки.
- Выделение нескольких файлов, контекстное меню, переименование и перемещение.
- Предпросмотр изображений, текста, PDF и поддерживаемых браузером аудио/видеоформатов.
- Корзина, восстановление и удаление навсегда с подтверждением.
- Подготовка файлов к обмену через раздел «Общие ссылки».
- Реальный объём сохранённых файлов, включая корзину.

По умолчанию разработка запускается с IndexedDB: данные отдельно для браузера и адреса сайта. Очистка данных сайта удаляет локальные файлы. Для серверного режима сборка запускается с `VITE_SERVER_STORAGE=1`; Python backend и закрытый nginx-маршрут описаны в [backend/README.md](backend/README.md).

Серверная версия поддерживает очередь, прогресс по каждому файлу, паузу и возобновление частями после обрыва. После закрытия страницы исходные файлы необходимо выбрать снова. Публичные ссылки пока отключены. Папки не скачиваются архивом; скачивание нескольких файлов может потребовать разрешения браузера. Независимые резервные копии требуют отдельной настройки.

## Проверки

```sh
npm test
```

Тесты Playwright используют `/usr/bin/chromium`. Для другой машины измените путь браузера в `playwright.config.js` или используйте установленный Playwright Chromium. Проверяются сохранение после перезагрузки, скачивание, предпросмотр, переименование, перемещение, корзина, восстановление вложенных файлов и мобильная навигация.
